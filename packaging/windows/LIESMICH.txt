AnMaCha Cast für Windows
========================

Start:            AnMaChaCast.exe  (das Programm: eigenes Fenster, Symbol im Infobereich, startet die Engine)
Fenster zu:       Automation und Streams laufen im Hintergrund weiter (Symbol im Infobereich).
Beenden:          Rechtsklick auf das Symbol im Infobereich → „AnMaCha Cast beenden“.
Nur Engine:       AnMaChaCast-Headless.cmd  (ohne Fenster, für 24/7)
Autostart:        Autostart-einrichten.cmd  (startet AnMaCha Cast bei jeder Anmeldung im Infobereich)
Neues Token:      anmachacast-engine.exe --new-admin-token  (z. B. für die Android-App)

AnMaChaCast.exe ist das Programm, anmachacast-engine.exe die AnMaCha-Cast-Engine (Automation, Decks, Encoder) im Hintergrund.
Das Fenster nutzt Microsoft WebView2 (bei Windows 10/11 vorhanden).

Daten liegen in %LOCALAPPDATA%\AnMaChaCast\data (Medien, Einstellungen, verschlüsselte Passwörter).
ffmpeg (Audio-Engine) liegt im Ordner ffmpeg\.

Android-App im selben Netzwerk verbinden:
  1. AnMaChaCast-Netzwerk.cmd starten (oder im Setup-Assistenten „Im Netzwerk erreichbar“ wählen)
     (Windows-Firewall-Abfrage für "private Netzwerke" erlauben)
  2. In der App den PC auswählen und mit dem 6-stelligen Code koppeln.
